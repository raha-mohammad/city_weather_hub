# React App

A simple City Weather HUb application built with modern react+vite.

## 🚀 Features

- Based on Entered Zip code of your area,it will give the current weather
- Used External API to fetch current waether
- Component-based structure
- Responsive and fast

## 🛠️ Technologies Used

- **React** – UI library
- **Vite** – Build tool
- **Tailwind CSS** – Styling
- **JavaScript (ES6+)**

## 📦 Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
npm install
npm run dev
```
